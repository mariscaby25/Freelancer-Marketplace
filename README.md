# Freelancer Marketplace

A freelancer marketplace where clients can post jobs and freelancers can create profiles and apply for jobs.

## Features

- Client registration and login
- Freelancer registration and login
- Freelancer profiles
- Job posting
- Job browsing
- Job applications
- Application tracking
- Client/freelancer messaging
- Admin panel
- User management
- Job management
- Application management

## Technologies

- HTML
- CSS
- JavaScript
- React
- Node.js
- Express
- MySQL
